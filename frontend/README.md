# 🌍 GlobeTrotter - Travel Planning & Admin Platform

Globetrotter is an interactive multi-city travel planning and analytics platform built for the Odoo Hackathon.

---

## 🎨 Theme System
Includes dual-mode theme support adhering to specified color tokens:
- **Light Theme**: Warm White (`#FBF8F4`) + Terracotta (`#C1440E`)
- **Dark Theme**: Grayish Black (`#000000`) + Copper (`#D1824E`)

---

## 🚀 Key Features

1. **Authentication Pages**:
   - **Login**: Email & Password validation, show/hide password toggle, fast 1-click Demo Account Selector.
   - **Registration**: Account creation, travel style options, avatar picker, real-time password strength meter.
   - **Forgot Password**: 4-step wizard (Request Email -> 6-Digit OTP -> New Password -> Success Confirmation).

2. **Admin / Analytics Dashboard**:
   - Platform metrics & stats overview.
   - Interactive SVG analytics charts (Monthly trip creation trends & budget distribution donut chart).
   - Ranked destination cities & popular activities leaderboard.
   - Complete User Management table with search, role editing, account status toggles, and Add User modal.
   - Recent itineraries viewer modal and live system audit logs.

---

## 🛠️ Getting Started

```bash
# Install dependencies
npm install

# Run dev server
npm run dev

# Build for production
npm run build
```
